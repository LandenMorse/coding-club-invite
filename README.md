# Coding Club Meeting invite

ASCII-styled Three.js invite: **Coding Club Meeting, Mr. Derrick's classroom, Thursday, November 5th.**
Drag or tap the 3D text to spin it, or hit **PLAY** to run level 1-4 of Square Rage (rendered in ASCII over the invite).

`index.html` is a single self-contained file (Three.js, font and game inlined), so it works on GitHub Pages or by double-clicking it.

## Edit and rebuild

Edit `src/template.html`, then:

```
npm install
npm run build   # regenerates index.html
```

## Deploy

Settings -> Pages -> Deploy from a branch -> `main` / `(root)`.
